# Site officiel — Kévo D uchrist

Site statique responsive, prêt pour GitHub Pages.

## Fichiers à ajouter avant publication

Place ces trois fichiers à la racine du projet, au même niveau que `index.html` :

- `profil.png` — photo de profil
- `cover.jpg` — image de couverture
- `portfolio.pdf` — document à télécharger depuis le bouton du portfolio

Les noms doivent être exactement identiques (minuscules comprises). Le site fonctionne même sans la photo de profil, avec un monogramme de secours, mais ajoute les trois fichiers pour obtenir le rendu complet.

## Publier avec GitHub Pages

1. Décompresse ce ZIP sur ton ordinateur.
2. Ajoute `profil.png`, `cover.jpg` et `portfolio.pdf` à côté de `index.html`.
3. Crée un nouveau dépôt GitHub (par exemple `kevo-duchrist`).
4. Envoie tous les fichiers et dossiers du projet à la racine du dépôt.
5. Dans GitHub : **Settings → Pages**.
6. Dans **Build and deployment**, choisis **Deploy from a branch**, puis `main` et `/ (root)`, et clique sur **Save**.
7. Attends quelques minutes : GitHub affichera l'adresse publique du site dans la page Pages.
